# The VOID

The shared language for restoring the original mobile game as a browser-based experience.

## Language

**Original Game**:
The complete player-facing experience and content preserved in this repository, excluding the former OpenFeint integration as though it never existed.
_Avoid_: Legacy app, old game

**Web Port**:
The browser-based restoration of the Original Game for reasonably recent iOS and Android phones.
_Avoid_: Remake, rewrite

**Combat Prototype**:
The throwaway vertical slice that demonstrated the viability of flight, combat, input, and rendering in a mobile browser. It is evidence and reference material, not the Web Port itself.
_Avoid_: Web Port, production app

**Port Complete**:
The state in which the Web Port contains the full player-facing experience and content of the Original Game and is ready to be hosted publicly.
_Avoid_: Prototype complete, first release
